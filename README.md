# BillKeep releases

Tester builds of BillKeep (an offline billing app for small shops). This repository holds only the signed APK and the
`version.json` that the app reads to decide whether an update is required. It contains no source code.

- `version.json`: latest and minimum required build, APK link, SHA-256 checksum.
- `apk/`: the newest APK only.

To install: download the APK from `apk/` on your Android phone and open it (allow "install unknown apps" if asked).
Updates are offered inside the app. Always keep your data safe with Settings, Backup before updating.
